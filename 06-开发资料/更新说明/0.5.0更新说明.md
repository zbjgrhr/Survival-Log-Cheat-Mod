# 0.5.0 更新说明

桌面入口仍是：桌面 → 项目源码包 → 末日生存日志作弊器 → 末日生存日志作弊器.exe。

## 已实现

- 储物工具页的“固定所有设置（当前存档）”：记录持续开关、移速/时间/熟练度倍率、背包与储物格数和负重。开启后，更改这些选项会更新本存档的固定配置。重开游戏或面板后恢复。加钱、时间增减、拾取、开始酿酒、解锁等一次性动作不会重放。
- 旧版背包/储物固定配置继续保留。要扩展为全部设置固定，手动开启新按钮。取消固定后，当前值暂时保留；还原前请移走超出原始容量的物品。
- 时间/解锁页新增“探索不增加暴露值”。保持现有暴露值，阻止后续正向增长；不是清零按钮。
- 背包和储物柜增加横向、纵向滚动查看。滚轮上下滚动，Shift + 滚轮左右滚动，也可以拖动滚动条。未新增 Alt 快捷键。
- 共用网格组件的酿酒桶、工作台、烹饪、发电机等 15 种设施页面增加大网格滚动区域。交易、商店等独立界面仍使用原来的自动缩放，尚未全部统一为滚动。
